# NotesApp 📝

A modern React note-taking app with a polished dark theme and responsive UI.

Built to showcase clean React patterns, fast interactions, and a stylish Tailwind CSS design.

## ✨ Highlights

- **Create, view, and delete notes instantly** with smooth UI updates
- **Responsive layout** that adapts from mobile to desktop
- **Clean React state handling** using `useState` for input and note management
- **Polished styling** with Tailwind CSS and custom textured card backgrounds

## 🚀 What You’ll See

- A simple note form with title and content fields
- Dynamic note cards rendered from app state
- Easy note removal with a click
- A clean dark interface optimized for readability

## 🛠️ Tech Stack

- **React**
- **Tailwind CSS**
- **Vite**

## 📦 Installation

1. Clone the repository

```bash
git clone https://github.com/Ranjan-0007/NotesApp-.git
```

2. Go into the project folder

```bash
cd NotesApp
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm run dev
```

5. Open the local URL shown in your terminal (usually `http://localhost:5173`)

## 🧪 Why this project is useful

This app is a great example for:

- learning React hooks and controlled components
- practicing state immutability and list updates
- building a small, polished SPA with Tailwind styling
